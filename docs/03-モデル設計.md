# モデル設計 — Context-Conditioned Delta Transfer (CCDT)

## 出発点: 2025 の教訓

2025 の上位陣の結論は一貫している。

- 1 位 (BM_xTVC): 「純粋な AI ベース手法は統計ベースラインを安定して上回らなかった」。
  事前学習モデル + タンパク質埋め込み + 遺伝子頻度・発現量といった生物学的特徴の
  ハイブリッド。
- 2 位 (XLearning Lab): 単一細胞ではなく **疑似バルク** 表現に切り替え、
  残差学習付きの単純な全結合ネット + タンパク質埋め込み。
- 3 位 (Team Outlier): 細胞株横断の疑似バルクを使った統計フレームワーク +
  PDS 最適化のための大域線形スケーリング。
- Generalist 賞 (Altos Labs): flow matching で応答の異質性を表現し、7 指標すべてで安定。

つまり **疑似バルクの統計 + 少量の学習 + 明示的なスケール較正** が本命で、
end-to-end 深層モデルはこの規模のデータでは分が悪い。CCDT はこの形を素直に取る。

## 中核の問い: delta は文脈間で何が保存されるのか

遺伝子 g をノックダウしたときの発現変化 delta は、細胞株ごとに違う。
何が保存されるかを間違えると、転移そのものが成立しない。

**加算的な delta は保存されない。** 標的細胞株で発現していない遺伝子は
下がりようがないし、すでに飽和している遺伝子は上がりようがない。

**乗算的な効果（fold change）は保存される。** そこで転移演算子は:

```
fc_j    = (expm1(mu_src_j + d_j) + eps) / (expm1(mu_src_j) + eps)
d_tgt_j = log1p(expm1(mu_tgt_j) * fc_j) - log1p(expm1(mu_tgt_j))
```

擬似カウント `eps` がこの式の要。これがないと、ソース側でほぼ無発現の遺伝子が
発散した fold change を生み、標的側で発現している場合に爆発する。
`eps = 0.5` は中央値深度における 0.5 カウントに相当する量で、
信頼できない比の影響をそこで頭打ちにする。
標的側で沈黙している遺伝子は自動的に `d_tgt_j → 0` に潰れるので、
発現ゲートを手で設計する必要がない（`vcc/transfer.py`）。

## 全体の式

```
delta(g, c*) = alpha * M(g, c*) * [ b * D(g, c*) + (1 - b) * K(g, c*) ]
               標的遺伝子の成分だけはオンターゲットモデルで上書き
```

| 項 | 役割 |
|---|---|
| **D** 直接転移 | g の実測シグネチャを各ソース株から c* にリベースし、株類似度と細胞数で重み付け平均 |
| **K** プログラム kNN | どのソースでも摂動されていない標的（＝大多数）向け。遺伝子特徴から低ランク基底の負荷量を予測して展開 |
| **b** 信頼度 | D をどれだけ信じるか。実測シグネチャの裏付け量から決まる |
| **M** 効果量 | 摂動ごとの効果の大きさ。`nmae` と DE 系指標に効く（**`pds` には効かない** — 2026 の discrimination はコサインでスケール不変。`docs/05 §3e`） |
| **alpha** 大域スケール | MAE と PDS/pearson_delta のトレードオフを握る唯一のノブ。ホールドアウト細胞株で較正 |

各項が独立に検査・較正できることを優先している。end-to-end にしないのは、
どの項が効いているかを見ないまま締切を迎えるのが一番まずいから。

### D — 直接転移

株類似度 `line_similarity` は、2 つのベースラインプロファイルの
**差が大きい上位遺伝子だけ** で相関を取る。ハウスキーピング遺伝子はどの
ヒト細胞株でもほぼ同じで、全遺伝子で相関を取ると全ペアが r≈0.95 に潰れ、
必要な順位付けが消えるため。

シグネチャごとの重みは `n / (n + 30)`。40 細胞で測ったシグネチャは
ほぼノイズなので、素朴な平均に入れてはいけない。

### K — 低ランクプログラム + 遺伝子特徴 kNN

ノックダウンは 300 個の無関係な delta を作るのではなく、少数の共有プログラム
（リボソーム生合成ストレス、プロテアソーム負荷、細胞周期停止、統合ストレス応答…）
の混合を作る。c* にリベース済みの delta 行列を SVD して K≈30 成分を取ると:

- **ノイズ除去**: 40 細胞のシグネチャの大半はプログラム多様体の外側の
  ノイズで、射影すると落ちる。
- **外挿**: 未観測の標的遺伝子には自分のシグネチャがないが、**負荷量**なら
  遺伝子特徴から予測でき、基底が K 個の数値を全トランスクリプトームに戻す。

遺伝子特徴 (`vcc/features.py`) は 2 系統:

1. **文脈内共発現** — 標的細胞株の **コントロール細胞だけ** から計算した、
   その遺伝子と高分散遺伝子群との相関ベクトル。外部データ不要で常に使え、
   しかも文脈固有。同じ複合体・同じ経路の遺伝子は共変動し、
   ノックダウンはその共変動を潰す。
2. **外部埋め込み** — ESM2 等のタンパク質言語モデル、GO/STRING。
   2025 の上位 2 チームが揃って有効性を報告しているので入れる価値があるが、
   なくても動く（`.npz` を渡すだけの差し替え式）。

kNN カーネルは `power=3` で鋭くしている。遺伝子間コサイン類似度は
狭い帯域に集まるため、素朴な上位 k 平均は大域平均シグネチャに引き寄せられる。
それは「全摂動が同じに見える」という、PDS が最も嫌う失敗モードそのもの。

### M — 効果量

シグネチャを混ぜると共通成分に縮む。つまり kNN 再構成した delta は
実測より **系統的に小さい**。放置すると全予測が実測効果量分布の弱い側に集まり、
PDS が総崩れになる（`docs/02` §3）。`magnitude_gamma` で
近傍が示す効果量にどれだけ引き戻すかを制御する（0 で無効、1 で厳密一致）。

標的遺伝子がその細胞株でほとんど発現していない場合は
`mu_g / (mu_g + m0)` で減衰させる。発現していない遺伝子はノックダウンできない。

### オンターゲット項

CRISPRi は狙った遺伝子を落とす。これは実験について分かっている中で最も確実な
事実で、ガイドとプロモーターの性質であってダウンストリーム生物学とは別物なので
分けてモデル化する。ライブラリから遺伝子ごとの残存発現率の中央値を学習し、
未知遺伝子には全体中央値を使う。

**ただし PDS には効かない**（標的遺伝子は除外される）。効くのは MAE、
pearson_delta、そして DE 系指標（標的遺伝子はたいてい最有意ヒット）。

## 単一細胞への展開

`CellSampler` は各細胞を `control_cell + r_i * delta` として作る。
`r_i` は混合分布 — 非応答細胞のゼロスパイク（CRISPRi のエスケープは実在し、
摂動集団が二峰性になる主因）＋ 応答細胞のガンマ分布 — から引き、
その後 **平均がちょうど 1 になるよう正規化** する。

これで疑似バルク平均は異質性設定によらず予測 delta と厳密に一致するので、
疑似バルク系指標と DE 系指標を **独立に調整できる**。
非負クリップで平均がずれる問題は `_match_mean` が方向別に補正する
（上げる方向はシフト、下げる方向はスケール）。

コントロールアームに出す細胞と、摂動細胞の土台に使う細胞は
プールを分割して重複させない。同じ細胞が両アームに現れると DE 検定が歪む。

## 検証設計

ゼロショットは **細胞株ごと丸ごと** ホールドアウトしないと測れない
(`vcc.calibrate.evaluate_holdout`)。同一株内で摂動をホールドアウトするのは
別の（そしてずっと簡単な）問題を測っており、転移が全く効いていなくても
良い数字が出る。

## シミュレータでの実測値

`tests/synthetic.py` は、モデルが仮定する構造（共有低ランクプログラム、
クラスタ化した標的遺伝子、発現パターンが異なる細胞株）だけを持つ
4 細胞株の CRISPRi シミュレータ。**チャレンジデータではない** ので、
これらの数字は「配線が正しく通っていること」の証拠であって、
リーダーボード性能の予測ではない。
