# Virtual Cell Challenge 2026 — 課題整理

## タスク

未知の細胞株における CRISPRi ノックダウン応答の **ゼロショット予測**。

与えられるもの / 与えられないもの:

| | 内容 |
|---|---|
| 与えられる | 対象細胞株の **未摂動 (non-targeting) 細胞のみ** |
| 与えられる | ノックダウンする標的遺伝子のリストと、各摂動あたりの出力セル数 |
| **与えられない** | その細胞株で実測された摂動応答（＝これが「ゼロショット」の意味） |

出力は摂動後の **単一細胞レベル** の発現プロファイル (h5ad)。
`cell-eval prep` で `.vcc` に変換して提出する。

## データ

Arc が 6 細胞株（異なる組織由来）で CRISPRi × 10x Flex × Ultima シーケンスの
Perturb-seq を新規取得。3 株が検証フェーズ、3 株が最終評価に使われる。

## ルール上重要な点

- **学習データは任意**。公開摂動データセットでも自社データでもよい。
  → 2026 の新規データは配られないが、既存の CRISPRi スクリーンを総動員できる。
- 個人・研究室・企業・団体すべて参加可能。

## 2025 年からの変更点と、そこから読める設計方針

2025 は単一細胞株 (H1 hESC) 内での未知摂動の予測だった。2026 は
**細胞株そのものが未知** になる。これは問題の性質を変える:

- 2025 で有効だった「同じ細胞株の他の摂動から平均的な応答を借りる」戦略が、
  そのままでは使えない。細胞株間で **ベースライン発現が違う** ため、
  同じ遺伝子をノックダウンしても delta は同じにならない。
- したがって中核は **文脈間転移** になる。「どの遺伝子がどれだけ動くか」ではなく
  「どの *倍率* で動くか」を転移させる必要がある（`docs/03-モデル設計.md`）。

評価も 2025 の 3 指標から、NVIDIA と共同開発した新しい cell-eval による
**6 指標の集約** に変わった。単一指標への最適化を潰す意図が明示されている。

## 学習に使える公開データ

| データ | 内容 | 入手 |
|---|---|---|
| VCC 2025 | H1 hESC, 300 標的, ~30 万細胞 | `gs://arc-institute-virtual-cell-atlas/virtual-cell-challenge/2025/`（公開） |
| Replogle 2022 | K562 / RPE1 ゲノムワイド CRISPRi | Arc Virtual Cell Atlas |
| Tahoe-100M | 50 細胞株 × 薬剤摂動 | Arc Virtual Cell Atlas |
| scBaseCount | 大規模非摂動アトラス（文脈事前学習用） | Arc Virtual Cell Atlas |

**細胞株をまたぐ CRISPRi** が必要なので、少なくとも VCC2025 (H1) と
Replogle (K562, RPE1) の 3 文脈は必須。これが転移を学習する最小構成になる。
