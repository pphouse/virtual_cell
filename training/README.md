# DynaVelo の学習曲線

![学習曲線](training_curves.png)

| ファイル | 内容 |
|---|---|
| `training_curves.png` | 1 回目・2 回目の学習の 8 指標をエポックごとに重ねた図 |
| `training_log_v1.csv` | 1 回目（3,381 遺伝子 × 171 TF、143 エポック）のエポックごとの値 |
| `training_log_v2.csv` | 2 回目（3,625 遺伝子 × 189 TF、84 エポック）のエポックごとの値 |
| `stdout_v1.log` / `stdout_v2.log` | 学習スクリプトの標準出力そのまま |

列: `loss_train` は訓練の総損失、それ以外はテスト分割（10%）の値。
`velocity_cosine_test` は scVelo の速度とのコサイン類似度（`-velocity_loss_test`）。
総損失 = RNA 再構成 NLL + モチーフ再構成 NLL + 10,000 × 速度損失 + 10,000 × 一貫性損失 + 1,000 × (KL z0 + KL t)。

| | 1 回目 | 2 回目 |
|---|---|---|
| 停止エポック | 143 | 84 |
| テスト損失の最小（保存されたチェックポイント） | 12,644（エポック 133） | 13,762（エポック 74） |
| そのときの速度コサイン | 0.711 | 0.666 |

テスト損失が 10 エポック改善しないと止まる。2 回目は遺伝子が 244 個多いので再構成 NLL の分だけ損失が大きく、
損失の絶対値は 2 回の間で直接比べられない。速度コサインは 2 回目のほうが低い
（低発現の標的遺伝子を足したこと、早く止まったことの両方が効いている可能性がある。切り分けていない）。
